# AWS Academy Cloud Infrastructure Project

A documented set of guided AWS Academy labs covering core cloud infrastructure, storage, databases, scalability, and availability. The project focuses on understanding how AWS services work together and how to validate and troubleshoot each environment.

## Completed labs

- Build Your VPC and Launch a Web Server
- Introduction to Amazon EC2
- Working with Amazon EBS
- Build a Database Server
- Scale and Load Balance Your Architecture

## Skills demonstrated

- Designed VPC and subnet configurations using CIDR notation.
- Launched and validated EC2 instances and web-server connectivity.
- Attached, configured, and verified persistent EBS storage.
- Configured database resources and reviewed service connectivity.
- Applied IAM concepts and security controls within guided environments.
- Tested load balancing, scaling, availability, and common connectivity issues.

## Services and concepts

- Amazon VPC, public and private subnets, routing, and internet gateways
- Amazon EC2 and security groups
- Amazon EBS
- AWS Identity and Access Management (IAM)
- AWS database services
- Elastic Load Balancing and Auto Scaling
- Availability, monitoring, and structured troubleshooting

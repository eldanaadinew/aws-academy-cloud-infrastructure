# Lab Summary

## VPC and web server

Built a VPC with subnetting, routing, internet access, security controls, and an EC2-hosted web server. Verified the instance state, route configuration, security-group rules, and browser connectivity.

## Amazon EC2

Practiced launching, configuring, monitoring, and managing EC2 instances. Reviewed instance states, network settings, and the checks used to isolate access problems.

## Amazon EBS

Created and attached persistent block storage, verified the volume relationship to the instance, and reviewed how storage remains separate from temporary compute resources.

## Database server

Configured database resources in the guided environment and reviewed network placement, access controls, and application-to-database connectivity.

## Scaling and load balancing

Configured a load-balanced, scalable architecture and reviewed how health checks, multiple instances, and Auto Scaling improve availability.

## Result

Completed all five guided labs and documented the service relationships, validation steps, and troubleshooting process used throughout the work.
